# Directors Cut

A free, premium video editing app for iPhone and Mac. No watermarks, no subscriptions, no data harvesting.

## Features

- Multi-track timeline editing with trim, split, and reorder
- Real-time Metal-powered preview with GPU effects
- Color grading, LUTs, keyframe animation, speed ramping
- AI auto-captions, background removal, motion tracking
- 4K/HDR export with no watermark
- Privacy-first: all AI runs on-device, nothing leaves your phone

## Tech Stack

- **Swift + SwiftUI/UIKit** - Native Apple performance
- **AVFoundation** - Video composition and playback
- **Metal** - GPU-accelerated effects and preview
- **Core ML + Vision** - On-device AI features
- **WhisperKit** - Speech-to-text captions

## Requirements

- iOS 17+ / macOS 14+
- Xcode 15+

## Building

```bash
# Open in Xcode
open Package.swift

# Or build from command line
swift build
```
